## 三、语法覆盖（分级别归纳）

### A1 入门级（100 处语法点睛）
- **be 动词**：am / is / are 的肯定与否定（am not）
- **一般现在时**：含第三人称单数（-s）、否定（do not / don't）
- **There be 句型**：单复数、与数量词/形容词结合
- **形容词比较级 / 最高级**：younger than、the best、the most important
- **情态动词**：can（能力）、should（建议）、must（必须）、may（请求）
- **介词**：in / on / at / near / beside / in front of / from...to
- **冠词**：a / an 的区别；**名词复数**；**名词所有格**（'s）
- **代词**：物主代词 its、相互代词 each other
- **数词**：基数词、序数词（first / second）
- **频度副词**：always / often / sometimes / never
- **连词**：and / but / because
- **双宾语**：give + 人 + 物
- **动名词作宾语**：like / love doing
- **时间 / 日期 / 价格表达**：o'clock、January first、基数词 + yuan
- **提问句式**：How many / How much；**祈使与感叹**：That is OK

### A2 初级（100 处语法点睛）
- **一般过去时**：规则动词 -ed + 不规则动词（had / was / rode）
- **过去进行时**：was walking
- **一般将来时**：will + 动词原形、be going to
- **when 引导时间状语从句**；**if 引导条件状语从句**
- **情态动词**：could（能力/否定）、should、must / must not、have to、may、can
- **比较级 / 最高级**：bigger than、more...than、one of + 复数、the best
- **不定式表目的**：to reach / to meet / to share
- **动名词**：作主语（Keeping healthy）、作宾语（spending）
- **It takes + 人 + 时间 + to do**；**spend + 时间 + on**
- **间接引语**：said I should...
- **定语从句（that）**：a job that I love
- **礼貌请求句式**：Could you...? / Can I help you? / May I...?
- **频度表达**：twice a week；**序数词**：eighth

### B1 中级（100 处语法点睛）
- **现在完成时**：have / has + 过去分词，与 since / for 连用
- **过去完成时**：had been
- **现在完成进行时**：have been thinking
- **第一条件句**：If...will / can
- **第二条件句**：If I could..., I would...
- **定语从句**：who / where / that（含 where 引导非限制性定语从句）
- **被动语态**：is built、现在进行时被动（are being forgotten）
- **used to do**：过去常常
- **动名词作主语 / 宾语**：Setting goals、Learning
- **make + 宾语 + 宾补**：make my life warm、make our family closer
- **让步 / 对比**：while 表对比、even though、even when、no matter what、whenever
- **疑问词引导的宾语从句**：where my money goes
- **比较结构**：more than、fewer / less、the warmest

### B2 中高级（100 处语法点睛）
- **whether 引导主语从句**；**whether...or...**
- **非限制性定语从句（which）**
- **被动语态进阶**：情态动词被动（must be managed）、现在完成被动（has been hidden）、进行被动（are being lost）
- **现在分词作状语**：killing sea animals
- **the more...the more**：越……越……
- **第一条件句**：If...will / follow / may
- **让步 / 对比**：though、while 表让步
- **as if 引导方式从句**
- **动名词**：作主语/宾语、worth doing、instead of doing
- **定语从句省略关系词**：a skill everyone needs
- **may 表推测**：may replace

### C1 高级（100 处语法点睛）
- **倒装句**：Not only has...（否定词开头倒装）
- **what / whatever / wherever 从句**：主语从句、宾语从句、让步从句
- **比较与取舍结构**：not so much...as、as...as、no less...than、too...to、rather than
- **不定式被动**：to be repaired
- **过去分词作状语**：driven by...
- **leave + 宾语 + 宾补**：leaves people feeling emptier
- **第二条件句**：If...would / could...should we?
- **多并列主语从句**：What..., how..., whether...
- **插入语**：if fortunate、though it connects us
- **情态动词被动**：must be balanced、cannot be answered

### C2 精通级（100 处语法点睛）
- **虚拟语气**：as though / as if + were、Had we...（倒装省略）
- **强调句**：it is...that
- **同位语从句**：the awareness that、the conviction that
- **倒装句**：Not only + 助动词 + 主语、Nor + 助动词 + 主语
- **非限制性定语从句（which）**（多重复现）
- **递进比较**：the more...the more...the less
- **对比 / 取舍结构**：not...but...、not merely...but...、less...than...
- **far from + 动名词**：远非……
- **分词**：现在分词作状语 / 定语 / 伴随
- **the same...that**、**whether 主语从句**、**where 地点状语从句**
- **不定式**：作主语 / 表语 / 后置定语
