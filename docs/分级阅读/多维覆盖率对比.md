# 分级阅读 × CEFR 多维覆盖率对比

> 本文档回答：已完成的 600 篇分级阅读（A1–C2 各 100 篇），相对 CEFR / English Profile 标准，在**语法、词汇量、话题域、短语与搭配**四个维度上的覆盖率分别是多少、哪条线是短板、补强优先级如何。
>
> 对比方法：每个维度都以权威标准为「标准侧」，以 600 篇文章实际标注/出现的内容为「实际侧」，逐级量化覆盖率。

## 〇、四维覆盖率总览

| 维度 | 标准依据 | 综合覆盖率 | 等级评价 |
| --- | --- | ---: | --- |
| 语法 | English Grammar Profile（EGP） | **约 63%** | 中，B2 最弱 |
| 话题域 | CEFR 话题清单 | **约 90%** | 良好 |
| 词汇量 | English Vocabulary Profile / CEFR 参考词汇量 | **约 40%** | 偏低，B2+ 严重不足 |
| 短语与搭配 | EVP（动词短语/习语/依赖介词/搭配） | **约 15%** | ⚠️ 严重不足 |

> 一句话结论：**「话题」这条线已经铺得很全，「语法」中等，「词汇量」偏低，「短语与搭配」几乎空白**——短语与搭配是当前最大的短板，其次是词汇量。

### 2.2 与 CEFR 参考词汇量对比

| 级别 | 累计词元（实际） | CEFR 参考词汇量（累计） | 覆盖率 |
| --- | ---: | ---: | ---: |
| A1 | 556 | ~500 | **111%** ✓ |
| A2 | 890 | ~1,250 | **71%** |
| B1 | 1,278 | ~2,500 | **51%** |
| B2 | 1,727 | ~3,500 | **49%** |
| C1 | 2,491 | ~8,000 | **31%** |
| C2 | 3,175 | ~16,000 | **20%** |

> 说明：CEFR 参考词汇量是「学习者应掌握的词」（含被动认知），阅读材料是「输入文本实际出现的词」，二者口径不同——阅读输入词通常会略低于目标词汇量，但差距不应超过一个数量级。这里的趋势是：**A1 达标，A2 起逐步掉队，C1/C2 掉到 20%–31%**，说明中高级阅读材料的词汇广度明显不足。

### 2.3 词汇维度结论

- **基础词汇（A1）覆盖充分**，高频生活词齐全。
- **A2–B1 偏薄**：话题词（购物、旅行、工作、健康）的词汇密度不够。
- **B2–C2 严重不足**：抽象词、学术词（AWL）、近义精细词、习语化表达的输入量远低于该级应有水平。

## 四、维度 4：短语与搭配（English Vocabulary Profile）

短语维度拆成四类：**动词短语（phrasal verbs）、习语（idioms）、依赖介词（dependent prepositions）、固定搭配（collocations）**。以 600 篇「词与短语」标注的实际数量，对照各级应掌握量（参考值，来自 Cambridge 系列大纲的通行量级）。

### 4.5 短语维度结论

**这是四条线里最严重的一条**（综合覆盖率约 15%）：

1. **动词短语严重不足**：A1–B1 勉强及格线以下（26%–40%），B2–C2 掉到 3%–11%。而动词短语恰恰是 B2 以上口语与写作的地道度关键。
2. **习语几乎空白**：B1–C2 每个级别只有 1–4 条，远低于「几十上百条」的应有量。
3. **依赖介词基本为零**：B2、C1 两个级别一个都没标（interested in / good at / depend on 这类），是明显断层。
4. **固定搭配密度偏低**：现有「词与短语」以单个词和简单搭配为主，缺少 make a decision / pose a threat / reach a consensus 这类进阶搭配。

## 五、综合结论

| 优先级 | 维度 | 覆盖率 | 补强方向 |
| --- | --- | ---: | --- |
| 🔴 P0 | 短语与搭配 | ~15% | 逐级补动词短语、习语、依赖介词、固定搭配，重点 B2–C2 |
| 🟠 P1 | 词汇量 | ~40% | B2–C2 增加抽象词、学术词、近义词的输入 |
| 🟡 P2 | 语法 | ~63% | 补 B2 条件句系统、间接引语、倒装/强调/虚拟 |
| 🟢 P3 | 话题域 | ~90% | 基本无需补 |

**一句话**：600 篇在「**话题**」上已经铺满，「**语法**」中等，「**词汇**」和「**短语搭配**」是两大短板——尤其是**短语与搭配**，几乎是从零开始补。补强时应优先把动词短语、习语、依赖介词、固定搭配织进每级阅读材料里。
