# CEFR 分级说明

> 本文档依据两个权威来源重新整理：① 欧洲理事会（Council of Europe）**CEFR Companion Volume (2020)** 的官方能力描述量表；② 剑桥大学领衔的 **English Profile 项目** 发布的 **English Grammar Profile（EGP）** 英语语法分级清单。相比泛泛的「语法列表」，这两者分别回答了「每个等级能做什么」与「英语在每个等级具体覆盖哪些语法结构」。

## 〇、关于「语法清单」来源的重要说明

**CEFR 官方本身不列出任何等级的语法清单。** CEFR 是一套「能做（can-do）」描述框架，面向所有语言，只描述学习者「能用语言完成什么任务」，而不规定「每个等级该学哪些语法」。官方原文明确写道：*「要制定一套适用于所有语言的语法结构进阶量表是不可能的」*（Council of Europe, 2001, p.113）。

那么市面上的「A1 语法有哪些、B1 语法有哪些」清单从何而来？主要来自两个后续的权威项目：

1. **English Grammar Profile（EGP）**——剑桥英语考评部（Cambridge English）领衔的 English Profile 项目，基于**剑桥学习者语料库（Cambridge Learner Corpus）**，记录了不同等级学习者在考试中**实际产出**的语法结构，共 1200 余条分级「can-do」描述，是当前**最权威、最精细的英语语法分级标准**。
2. **Core Inventory（British Council / EAQUALS）**——记录教师和主流教材在**教学上通常覆盖**的语法，偏教学实践。

本文档的「语法清单」以 **English Grammar Profile** 为准，能力描述以 **CEFR 官方 Companion Volume (2020)** 为准。

---

## 一、总体框架

CEFR 由欧洲理事会制定，将语言能力划分为三大阶段、六个级别，用「能做」方式描述学习者实际能用语言完成什么任务。

| 大阶段 | 级别 | 英文名 | 中文名 | 定位 |
|--------|------|--------|--------|------|
| 基础使用者 Basic User | A1 | Breakthrough | 入门级 | 初步接触 |
| 基础使用者 Basic User | A2 | Waystage | 初级 | 基本交流 |
| 独立使用者 Independent User | B1 | Threshold | 中级 | 独立使用门槛 |
| 独立使用者 Independent User | B2 | Vantage | 中高级 | 有效交流 |
| 熟练使用者 Proficient User | C1 | Effective Operational Proficiency | 高级 | 熟练运用 |
| 熟练使用者 Proficient User | C2 | Mastery | 精通级 | 接近母语 |

> 核心思想：语言能力是连续、动态的，级别只描述「学习者当前能做什么」。每个级别从「听、说、读、写」四个维度展开，其中「说」细分为「互动对话」与「独白表达」。

## 二、官方能力描述量表（Companion Volume 2020）

CEFR 官方不列语法清单，但提供了「语法准确性（Grammatical Accuracy）」和「词汇控制（Vocabulary Control）」两套描述量表，逐级描述学习者**掌控语言的程度**。这是判断等级的官方核心依据。

### 2.1 语法准确性 Grammatical Accuracy

| 级别 | 官方描述（译文） |
| --- | --- |
| **C2** | 即使注意力被其他事情占据（如预先组织话语、留意他人反应），仍能保持对复杂语言的一致语法控制。 |
| **C1** | 始终保持高度的语法准确性；错误很少，且难以察觉。 |
| **B2** | 语法控制良好；偶尔会出现「口误」或非系统性错误，句子结构有小瑕疵，但很少见，且事后多能自行纠正。有相对较高的语法控制度，不会犯导致误解的错误。能较好掌握简单结构和部分复杂语法形式，但使用复杂结构时略显生硬、偶有不准。 |
| **B1** | 在熟悉语境中能以合理的准确性交流；总体控制良好，但带有明显的母语影响。会出现错误，但能清楚表达意图。能较准确地使用一套与可预测情境相关的常用「固定套路」和句型。 |
| **A2** | 能正确使用一些简单结构，但仍会系统性地犯基础错误；不过通常能让人明白其想表达的意思。 |
| **A1** | 对所学储备中的少数简单语法结构和句式仅能进行有限的控制。 |
| **Pre-A1** | 能用非常简单的词序原则构成短句。 |

### 2.2 词汇控制 Vocabulary Control

| 级别 | 官方描述（译文） |
| --- | --- |
| **C2** | 词汇使用始终正确、得体。 |
| **C1** | 能地道、恰当地使用不太常见的词汇。偶有轻微口误，但无重大用词错误。 |
| **B2** | 词汇准确性总体较高，偶有混淆或用词不当，但不妨碍交流。 |
| **B1** | 对基础词汇掌握良好，但表达更复杂思想或处理陌生话题时仍会出现明显错误。谈论熟悉话题时能恰当使用范围较广的简单词汇。 |
| **A2** | 能控制一套窄小的、应对具体日常需求的词汇储备。 |
| **A1** | （官方未提供描述） |

## 三、各等级详解（A1–C2）

> 每个等级的「语法清单」依据 **English Grammar Profile**；「词汇量」为学界与教学机构常用的近似参考值。

### A1 入门级（Breakthrough）

**官方总体描述**：能理解并使用熟悉的日常表达和非常基本的短语，满足具体需求。能介绍自己和他人，能就住址、所属物、认识的人等个人信息进行问答。当对方语速缓慢、发音清晰并愿意提供帮助时，能进行简单互动。

**语法清单（EGP）**

- **动词与时态**：be 动词（am/is/are）；一般现在时（含第三人称单数 -s）；现在进行时；have got / has got；祈使句
- **名词与代词**：人称代词（主格 I/you/he/she… 与宾格 me/you/him/her…）；物主形容词（my/your/his/her/its/our/their）；指示代词（this/that/these/those）；名词单复数（规则 -s/-es）；名词所有格 's
- **限定词与量词**：冠词 a/an/the（基础）；some/any/a lot of；How much / How many
- **形容词与副词**：基础形容词；and 连接两个形容词；频度副词 always/usually/sometimes/never
- **介词**：时间介词 in/on/at；地点介词 in/on/at
- **句型**：There is / There are；基本疑问句（语序 + What/Where/Who/How）；like/love/hate + -ing
- **情态动词**：can / can't（能力、可能、许可）

**词汇量参考**：约 500 词，以高频生活词汇为主（家庭、食物、数字、颜色、时间、常用动词）。

**考试对标**：雅思约 1.0–2.5 分；托福约 0–30 分；剑桥少儿英语（Starters/Movers）。

---

### A2 初级（Waystage）

**官方总体描述**：能理解与最直接相关领域（个人和家庭信息、购物、当地地理、工作）相关的句子和常用表达。能在简单、常规的任务中交流，进行直接的信息交换。能用简单的语言描述自己的背景、直接环境及切身需求。

**语法清单（EGP）**

- **动词与时态**：一般过去时（规则 -ed + 高频不规则动词）；过去进行时（was/were + -ing）；现在完成时（基础，have/has + 过去分词）；将来时 going to / will / 现在进行时表将来；现在完成时 vs 一般过去时（区分）
- **形容词比较**：比较级（-er、-ier、more、双写辅音、不规则）；最高级（基础）
- **情态动词**：should / shouldn't（建议）；can / could / might（请求、可能）；too / enough
- **名词与量词**：可数/不可数名词；some/any/much/many
- **条件句**：第一条件句（基础）
- **连词与顺序**：and/but/because/so；then/after
- **代词**：反身代词（myself/yourself/himself…）

**词汇量参考**：约 1,000–1,500 词，扩展到购物、旅行、餐饮、工作等生活领域。

**考试对标**：雅思约 3.0 分；托福约 31–41 分；剑桥 KET。

---

### B1 中级（Threshold）

**官方总体描述**：能理解在工作、学校、休闲等场合经常遇到的熟悉事物的清晰、标准输入。能应对旅行中可能遇到的大多数情况。能就熟悉或个人感兴趣的话题写出简单连贯的文本。能描述经历、事件、梦想、希望与抱负，并能简要说明理由和观点。

**语法清单（EGP）**

- **动词与时态**：现在完成时（for/since/already/yet/just）；现在完成进行时；过去完成时；used to / would（过去习惯）；将来形式（will / going to / 现在进行）
- **条件句**：第一条件句；第二条件句；（第三条件句与 wish/if only 在 B1–B2 过渡）
- **被动与间接引语**：被动语态（现在/过去一般时）；间接引语（say/tell 基础 backshift）
- **情态动词**：推测（must be / might be / can't be）；义务（must / have to / should / need to）
- **定语从句**：who / which / that / where / whose
- **比较**：比较级 + 最高级（完整）
- **其他**：动名词 vs 不定式；反身代词；连接词 although/however/because/so；附加疑问句（question tags）；冠词 a/an/the（进阶）

**词汇量参考**：约 2,000–3,000 词，覆盖日常、工作、学校、社会话题。

**考试对标**：雅思约 4.0–5.0 分；托福约 42–71 分；剑桥 PET。

---

### B2 中高级（Vantage）

**官方总体描述**：能理解复杂文本（无论是具体还是抽象话题）的主旨，包括自己专业领域内的技术性讨论。能与母语者进行相当流利、自然的互动。能就广泛话题写出清晰、详细的文本，能就时事问题阐述观点，并分析各种选择的利弊。

**语法清单（EGP）**

- **条件句与虚拟**：第三条件句；混合条件句；wish/if only（+ 过去完成）；条件替代式 unless/provided/as long as/in case/supposing
- **被动与间接引语**：被动语态全系（含进行、完成被动）；reporting passives（It is said that…）；have/get something done；间接引语（完整 backshift）
- **情态动词**：must/might/can't + have done（推测过去）
- **从句与非谓语**：非限制性定语从句；分词短语作状语（Doing / Having done / Done）
- **强调与结构**：倒装（Not only…but also，基础）；强调句（It is…that / What I need is…）；虚拟语气（It is essential that he be / If I were，基础）；强调 do/did；语篇标记（discourse markers）；动名词 vs 不定式（stop doing vs stop to do）；复合形容词

**词汇量参考**：约 3,000–4,000 词（主动），被动可达 6,000 词，覆盖抽象、社会、学术话题。

**考试对标**：雅思约 5.5–6.5 分；托福约 72–94 分；剑桥 FCE；国内约高考优秀～大学英语四级（CET-4）。

---

### C1 高级（Effective Operational Proficiency）

**官方总体描述**：能理解各种高要求、较长的文本，并识别其隐含含义。能流利、自然地自我表达，无需明显费力寻找措辞。能在社交、学术和职业场合灵活、有效地使用语言。能就复杂话题写出清晰、结构良好、详细的文本，展现出对组织模式、连接词和衔接手段的熟练运用。

**语法清单（EGP）**

- **倒装与强调**：高级倒装（Never have I / Not only did / Hardly had / Only then）；强调句 cleft（It is…that / What…is）；强调 do/did
- **虚拟与条件**：虚拟语气（高级，It is essential that he be）；混合条件句（高级）；wish/if only
- **分词与非谓语**：分词独立结构（The meeting being over…）；分词短语（高级）
- **名词化与语体**：名词化 nominalization；语体/语域切换 register；省略与替代 ellipsis/substitution
- **衔接与结构**：语篇衔接（Furthermore/Nevertheless/Consequently/In contrast）；复杂从句嵌套；平行结构 parallelism；高级被动（have/get something done + reporting passives）

**词汇量参考**：约 8,000 词以上，含大量学术词汇（AWL）、抽象概念词、习语和地道搭配。

**考试对标**：雅思约 7.0–8.0 分；托福约 95–120 分；剑桥 CAE；国内约大学英语六级（CET-6）优秀～考研英语高分。

---

### C2 精通级（Mastery）

**官方总体描述**：能轻松理解几乎所有听到和读到的东西。能总结来自不同口头和书面来源的信息，连贯地复述论点和说明。能自然、非常流利、精确地自我表达，即使在最复杂的情况下也能区分细微的语义差别。

**语法清单（EGP）**

- **精熟自动运用**：A1–C1 全部语法内化为无意识、精确的语用能力，不再「学习新语法」。
- **精微情态**：nuanced modality（认知情态与道义情态的精细区分）
- **复杂句法**：复杂嵌入从句、同位语（appositives）、平行结构
- **修辞与风格**：反讽 irony、缓和语气 hedging、名词化 nominalisation、含蓄陈述 understatement
- **语篇连贯**：extended text coherence（跨长篇文本的连贯组织）
- **语域精确切换**：根据读者与目的，在极正式书面语与高度口语化俚语之间自如切换

**词汇量参考**：约 16,000 词以上，接近受过良好教育的母语者。

**考试对标**：雅思约 8.5–9.0 分；托福约 120 分；剑桥 CPE；国内约英语专业八级（TEM-8）优秀～母语者水平。

## 五、能力自评要点

判断自己处于哪个级别，建议以「能否稳定、自然地完成该级别的任务」为标准，而不是「偶尔能做到」：

1. **A1–A2**：能否应对基本生存交流（问路、点餐、购物、自我介绍）。
2. **B1**：能否独立处理旅行中的大多数情况，能否就熟悉话题进行连贯叙述。
3. **B2**：能否与母语者自然互动，能否就广泛话题写清晰文章、论证观点。
4. **C1–C2**：能否在学术/职业场合流利、精确、灵活地使用语言，识别隐含意义和细微差别。
