## 课程体系

本笔记库按 CEFR 欧标等级组织，每个课程包含视频课、口语操练、词汇积累、语法重点、智能复习、角色扮演等小节。

| 等级 | 说明 |
|------|------|
| A1 基础入门级 | 能用英语自我介绍，并应对基本需求 |
| A2 初级 | 能制定计划，并与当地人聊熟悉的话题 |
| B1 中级 | 能自信地分享经验和讨论各种话题 |
| B2 高级 | 可以表达抽象的想法和讨论特定的主题 |

> 使用左侧导航按等级浏览课程，或使用顶部搜索框检索任意单词、短语或语法点。
