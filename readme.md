A1: 基础入门级
    A1:能用英语自我介绍，并应对基本需求。
    基层入门级：掌握必备的沟通技巧，描述自己、问路和表达时间。

A2: 初级
    A2:能制定计划，并与当地人聊熟悉的话题。
    初级A:解锁讲故事的技能，聊一聊聊聊你的一天，过去的经历和未来的计划。
    初级B:驾驭常见语境，在用餐、购物和制定计划时流畅表达。

B1: 中级
    B1:能自信地分享经验和讨论各种话题。
    中级A:应对现实生活中的挑战，做出比较，描述病情和处理日常事务。
    中级B:自信地表达自己，分享观点，做出决定和提供建议。
    中级C:展开更深入的话题，回顾遗憾、分享回忆和阐明价值观。

B2: 高级
    B2:可以表达抽象的想法和讨论特定的主题。
    商务英语:进阶升级，像母语者一样与同事讨论、演讲展示和拿下面试。


选修主题课程:核心课程以外的多级别拓展课程。
    旅游英语A:轻松出国游，玩转机场、酒店和旅游景点。
    旅游英语B:解锁非凡旅行，掌握关于用餐、购物以及与当地人交谈的实用表达。
    校园英语A:留学高分通关，自信满满地与教授和同学交流互动。
    校园英语B:留学轻松无碍，游刃有余地参与辩论和小组讨论。
